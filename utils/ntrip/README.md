# RTK2go Station Finder

[RTK2go](https://rtk2go.com/) is a free NTRIP caster for RTCM streams used for RTK corrections.
Find nearby community base stations with the [RTK2go station finder](https://rtk2go.entr0-pi.com/),
built by entr0-pi and based on the [ntrip-stations repository](https://github.com/entr0-pi/ntrip-stations).
