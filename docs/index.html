🔍 Find your chip and USB type

Two things decide your firmware file: the chip (ESP32, ESP32-S3 or ESP32-C3) and, for S3 and C3, the USB type: native USB gives _usb, a USB-to-UART bridge gives _uart.

  1. Install esptool
    pip install esptool
  2. Read the chip

    Plug the board in (if it is not detected, hold BOOT while plugging in), then run:

    esptool chip-id

    With esptool 4.x the command is esptool.py chip_id. If several ports are connected, add --port COM5 (Windows) or --port /dev/ttyUSB0 (Linux).

    Look for the line “Chip is …” (example)
    Chip is ESP32-S3 (QFN56) (revision v0.1)
Features: WiFi, BLE, Embedded PSRAM 8MB
  3. Read the flash size (optional)
    esptool flash-id

    Look for Detected flash size: 8MB. The firmware needs 4MB or more (esptool 4.x: esptool.py flash_id).

  4. Find the USB type

    pyserial is installed with esptool, so you can list the ports with their USB IDs:

    python -m serial.tools.list_ports -v
    Read the “USB VID:PID=” value (example)
    COM5
    desc: USB Serial Device (COM5)
    hwid: USB VID:PID=303A:1001 ...
    VIDDeviceFirmware
    303AEspressif native USB_usb
    10C4CP210x bridge_uart
    1A86CH340 / CH9102 bridge_uart
    0403FTDI bridge_uart
  1. Open the tool

    Use Chrome or Edge on a computer (it needs Web Serial). Nothing to install.

    Open Espressif esptool-js ↗
  2. Connect

    Plug the board in, click Connect, and choose your board’s port in the browser dialog. If it fails, hold BOOT while plugging in and try again.

  3. Read the log

    The tool detects the chip when it connects and prints it in its log (for example ESP32-S3), with the chip features. That is your chip.

  4. Disconnect

    Click Disconnect or close the tab. Only one program can use the port at a time, so do this before flashing with another tool.

This tool tells you the chip, not the USB type. For the USB type, use the USB type (no tools) tab.

Two USB connectors on your board? Use the type of the one you flash through. Boards labelled “UART” or “COM” usually go through a bridge; the one labelled “USB” is usually native.
